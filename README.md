# ระบบเรียนออนไลน์ (LMS) — GitHub Pages + Supabase

## ติดตั้ง
1. แตก zip แล้วลากไฟล์ทั้งหมดลง repository บน GitHub (ใช้ github-upload.html ช่วยเปิดหน้าอัปโหลดได้)
2. Settings → Pages → Branch main / root
3. ฐานข้อมูลสร้างแล้ว (ตาราง web_students, web_submissions) และ URL/anon key ใส่ใน config.js แล้ว ไฟล์ schema.sql ไว้สำรอง

## ค่าที่ต้องแก้ใน config.js
- COURSE_CODE / COURSE_NAME: **ใส่รหัสและชื่อวิชาจริง** (ตอนนี้เป็นค่าตั้งต้น)
- ADMIN_USER / ADMIN_PASS: ค่าตั้งต้น admin / admin1234 **ควรเปลี่ยนก่อนใช้งานจริง**
- FS_GRACE=5 วินาที, SUSPEND_HOURS=2, LATE_HOURS=3

## เนื้อหา (content.js)
มีครบ 12 หัวข้อ แต่หน่วยที่ 1 เท่านั้นที่มีเนื้อหาครบ (ใบความรู้ A4, ใบงาน 7 ข้อ, ข้อสอบ 20 ข้อ) หน่วย 2–12 แสดง "กำลังจัดทำ" รูปแบบข้อสอบ: Q("คำถาม","ข้อถูก","ผิด1","ผิด2","ผิด3","b|h") ระบบสลับตัวเลือกให้เอง

## ข้อจำกัดด้านความปลอดภัย (ตามจริง)
- ระบบทำงานฝั่งเบราว์เซอร์ทั้งหมด การล็อกอิน การล็อกเต็มจอ และการห้ามคัดลอก ผู้ที่มีความรู้ปิดหรือเลี่ยงได้ เหมาะกับการใช้ในห้องเรียนที่มีครูดูแล
- anon key และรหัสผ่านผู้ดูแลอยู่ในไฟล์ที่ผู้ใช้เปิดดูได้ รหัสผ่านนักศึกษาในตารางอ่านได้ด้วย anon key และเฉลยข้อสอบอยู่ใน content.js
- ถ้าต้องการความปลอดภัยสูง ควรย้ายการตรวจรหัสผ่านและเฉลยไปไว้ฝั่งเซิร์ฟเวอร์ (Supabase Edge Function)
